# 赛制与兵种

看懂 RoboMaster，第一件事是看懂「超级对抗赛」怎么打，以及场上每一台机器人是干什么的。

## 超级对抗赛怎么打

超级对抗赛（RMUC）是 RoboMaster 的核心赛事，一局比赛的关键设定：

- **时长**：约 7 分钟
- **目标**：率先摧毁对方**基地**，或在时间耗尽时血量占优
- **对抗**：红蓝双方各自派出多种机器人，在 26m × 15m 的场地内进行战术对抗

## 胜负判定

7 分钟结束后，按以下优先级判定胜负：

1. 基地已被摧毁的一方失败；若都未摧毁，则比**基地剩余血量**
2. 若基地血量相同，则依次比较：**前哨站状态 → 双方机器人伤害总和**

所以这不仅是「比谁火力猛」，更是「比谁守得住、配合得好」。

## 兵种一览

一支战队在超级对抗赛中通常部署多种机器人，各司其职：

| 兵种 | 数量（每方） | 主要职责 | 特点 |
| --- | --- | --- | --- |
| **步兵机器人** | 2 台 | 主力火力、战术配合、可打能量机关 | 发射 17mm 小弹丸，单发伤害低但射速快、灵活 |
| **英雄机器人** | 1 台 | 重型火力输出 | 发射约 42mm 大弹丸（高尔夫球大小），单发伤害高 |
| **工程机器人** | 1 台 | 取弹药、救援队友、兑换资源 | 带机械臂，血量与「等级」机制特殊 |
| **哨兵机器人** | 1 台 | 保护基地的最后一道防线 | **全自动**自瞄与自主导航，在固定轨道巡航 |
| **无人机** | 4 台 | 全局视野 + 飞弹攻击对方基地 | 空中机器人，受飞手考核与空域规则约束 |
| **雷达站** | 1 台 | 全局视野 + 敌方定位情报共享 | 固定在基地附近高台，全自动识别并广播敌方位置 |
| **飞镖系统** | 1 台 | 远程打击对方基地 / 前哨站 | 发射飞镖，单发伤害高、可越过地形直取目标 |

> 这也是为什么新手常从「步兵机器人」入手：它结构相对标准、任务明确，是理解整套电控系统的最佳载体。

## 场地上的关键元素

| 元素 | 作用 |
| --- | --- |
| 基地 | 双方的大本营，被打到 0 血即判负 |
| 前哨站 | 基地外围的防御建筑 |
| 能量机关 | 场地中央的「大符 / 小符」，激活后全队获得攻击 / 防御加成 |
| 补给站 | 提供弹丸与资源 |
| 高地 / 低地 / 缓冲坡 | 地形要素，影响移动与射界 |

## 从赛场到你的学习目标

你会发现，几乎所有兵种都离不开一个核心结构 —— **底盘 + 云台**：

- **底盘**：负责「到哪儿去」，对应运动控制（电机、PID、底盘运动学）
- **云台**：负责「看哪儿、打哪儿」，对应姿态解算与云台控制
