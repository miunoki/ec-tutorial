# 赛制与兵种

先说清楚超级对抗赛怎么打，再认识场上每一台机器人是干什么的。

## 超级对抗赛怎么打

超级对抗赛（RMUC）是 RoboMaster 的核心赛事，一局比赛大致是这样：

- **时长**：约 7 分钟
- **目标**：率先摧毁对方基地，或时间耗尽时血量占优
- **对抗**：红蓝双方各派一队机器人，在 26m × 15m 的场地上对抗

## 胜负判定

7 分钟打完，按下面的顺序分胜负：

1. 基地被打爆的一方直接输；都没打爆，就比基地剩余血量
2. 基地血量也一样，再比：前哨站状态 → 双方机器人伤害总和

所以不是火力猛就稳赢，守得住、配合好同样关键。

## 兵种一览

一队在超级对抗赛里通常上这么几种机器人，分工各不相同：

| 兵种 | 数量（每方） | 职责 | 特点 |
| --- | --- | --- | --- |
| 步兵机器人 | 2 台 | 主力输出、战术配合、打能量机关 | 17mm 小弹丸，单发伤害低但射速快、灵活 |
| 英雄机器人 | 1 台 | 远程英雄负责吊射基地，近战英雄负责提供正面火力 | 42mm 大弹丸（高尔夫球大小），单发伤害高 |
| 工程机器人 | 1 台 | 取弹药、救队友、兑换资源 | 带机械臂，有独立的血量与等级机制 |
| 哨兵机器人 | 1 台 | 全自主机器人，提供地面火力 | 在固定轨道上巡航，全自动自瞄和导航 |
| 无人机 | 4 台 | 空中视野、飞弹打基地 | 空中单位，受飞手考核和空域规则约束 |
| 雷达站 | 1 台 | 看全场，给队友报敌方位置 | 架在基地旁的高台上，自动识别并广播 |
| 飞镖系统 | 1 台 | 远程打击基地、前哨站 | 发飞镖，单发伤害高，能越过地形直接命中 |

## 场地上的关键元素

| 元素 | 作用 |
| --- | --- |
| 基地 | 双方大本营，血量清零即判负 |
| 前哨站 | 基地外围的防御建筑 |
| 能量机关 | 场地中央的大符/小符，激活后全队加攻击或防御 |
| 补给站 | 提供弹丸和资源 |
| 高地 / 低地 / 缓冲坡 | 地形，影响移动和射界 |
