# RoboMaster 是什么

## 一句话概括

RoboMaster 机甲大师高校系列赛，是由**大疆创新（DJI）**发起的全球性机器人竞技赛事，也是**全球首个射击对抗类的机器人比赛**。参赛队伍自主研发多种机器人，在固定场地里用「弹丸」互相射击、执行任务，最终以摧毁对方基地或血量占优分出胜负。

它不只是一场比赛，更是一个「青年工程师的练兵场」：从机械结构、电子电路、嵌入式软件到机器视觉与人工智能，几乎每一个环节都由学生亲手完成。

## 起源与发展

RoboMaster 的前身是大疆的「大学生夏令营」，一路演化成今天的全球赛事：

| 年份 | 里程碑 |
| --- | --- |
| 2013 | 大疆创办首届大学生夏令营（仅 24 人），任务是实现基于机器视觉的自主移动打靶 |
| 2014 | 夏令营扩至 100 人，开展 4v4 机器人射击对抗，竞赛规则雏形诞生 |
| 2015 | **首届机甲大师赛**（英文名 RoboMasters）正式举办，首创 5v5 射击对抗，吸引 3000 余名大学生 |
| 2016 | 研发出新一代机器人裁判系统，并首次引入海外战队 |
| 2017 | 英文名正式改为 **RoboMaster**，对抗升级为 7v7，新增工程机器人 |
| 2018 | 新增哨兵机器人；大能量机关改用动态火焰特效手写数字 |
| 2019 | 大能量机关改为「五片装甲板大风车」；同年大疆推出教育机器人 RoboMaster S1 |

> 总决赛通常每年八月在深圳湾体育中心（春茧体育馆）举行。

## 为什么它「不一样」

绝大多数机器人比赛是「一个任务、一个机器人」，而 RoboMaster 是**多兵种、多学科的团队对抗**：

- **机械**：机器人本体设计与加工，底盘、云台、发射机构、机械臂
- **电控**：电路设计、嵌入式开发、运动控制、通信与整车调试
- **视觉 / 算法**：自瞄、目标识别、能量机关击打、自主决策
- **项目管理**：预算、进度、供应链、对外合作

一台机器人，从设计、制作到比赛操控，**全部由学生自主完成**。这也是它被称作「最接近真实工程」的学生赛事的原因。

## 系列赛体系

RoboMaster 高校系列赛下分四大方向，各有侧重：

| 赛项 | 简称 | 形式 | 特点 |
| --- | --- | --- | --- |
| 超级对抗赛 | RMUC | 多兵种团队对抗 | 最核心、最综合的赛事，本文重点 |
| 高校联盟赛 | RMUL | 1v1 / 3v3 / 工程挑战 | 门槛更低，适合练兵 |
| 高校单项赛 | RMUT | 单台机器人专项 | 步兵竞速射击、工程采矿、飞镖打靶、英雄吊射 |
| 高校人工智能挑战赛 | RMUA | 全自动射击对抗 | 机器人自主感知、决策、运动规划 |

## 为什么值得你投入

对刚加入电控组的你来说，RoboMaster 的意义在于：

1. **真实**：要解决的都是「让机器人在对抗里可靠地动起来」的真问题，不是玩具
2. **系统**：逼着你去打通「硬件 → 软件 → 控制 → 调试」的完整链路
3. **成长**：和一群目标一致的人，把一个复杂系统从零做出来并送上赛场
