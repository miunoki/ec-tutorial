# RoboMaster 是什么

> **官方定义**：RoboMaster 机甲大师高校系列赛，作为全国大学生机器人大赛旗下赛事之一，是专为全球科技爱好者打造的机器人竞技与学术交流平台。

RoboMaster 是由**大疆创新（DJI）**发起的、**全球首个射击对抗类机器人比赛**。参赛队伍自主研发多种机器人，在固定场地内用「弹丸」互相射击、执行任务，最终摧毁对方基地或血量占优者获胜。

它也是一部「青年工程师的技术兴替史」——下面这篇编年史，就是这条脉络的完整梳理：冠军更替、规则更新，以及哪些技术沉淀了下来、哪些被淘汰。

## 创世纪元（2015–2016）

**2015 首届**由电子科技大学 **One Point Five** 战队夺冠。那时规则还是 5v5、机器人对抗的雏形，技术也相对原始：底盘多为普通轮、瞄准基本靠手动，胜负更多拼操作与临场。

**2016 赛季**电子科大以 One Point Five S 卫冕。这一年最关键的是**新一代机器人裁判系统**上线，让血量、弹丸命中、能量机关激活都能实时客观判定。从此机器人必须按规范预留安装位与通信接口——这也是电控组至今都要对接的外部约束。

## 华南虎时代（2017–2018）

**2017**：对抗升级为 **7v7**，新增**工程机器人**（取弹、救援）。华南理工大学 **华南虎**首次夺冠。

**2018**：新增**哨兵机器人**（全自动巡航守家）；大能量机关改为**火焰特效手写数字**，视觉识别难度陡增。华南虎成功卫冕。

这两年定下了此后十年不变的兵种骨架：步兵、英雄、工程、哨兵、无人机。

## 变革与疫情（2019–2021）

**2019**：大能量机关改为**五片装甲板的旋转大风车**，要求在 8 米外击打旋转扇叶——「远距离 + 运动预测」成为视觉与电控的新难题。东北大学 TDT 凭借**无人机「无敌输出」**战术夺冠：激活能量机关拿到 2 倍输出加成后，无人机倾泻火力直接打爆基地。

**2020**：疫情取消线下赛，改为**线上评审**，东北大学线上再夺一冠。这一年新增**飞镖系统、雷达站**两大兵种。

**2021**：上海交大交龙首冠。规则动了「大手术」：引入自动/平衡步兵、工程机器人改**采矿**、空中机器人取消原发射机构改为 17mm 机动发射机构、引入新经济体系。其中对空中机器人的改动，本质上就是**给 2019 年的「无人机无敌流」踩刹车**。

::: tip 技术特写：滑环与小陀螺
**滑环（导电滑环）**是一种能「边旋转、边传输电力与信号」的装置。没有它，底盘与云台之间的线缆转一圈就会扭断，云台只能有限角度摆动；有了它，云台就能**无限 360° 连续旋转**——这也是视觉自瞄能锁定任意方向目标的硬件前提。

滑环带来的「意外之喜」是**小陀螺战术**：既然云台能无限转，底盘也可以——让步兵一边**高速自旋**、一边靠云台反向补偿锁住目标。旋转的车体让装甲板变成高速移动靶，对手很难稳定命中，弹丸打到旋转的装甲板也容易弹开。

这一战术一度盛行，随后规则出手：限制自旋转速、禁止变速与偏心旋转等手段，给小陀螺「降温」。**战术退潮了，但滑环本身留了下来**——今天几乎每台步兵的云台都离不开它，云台反向补偿也成了电控组的必修课。
:::

## 恢复期（2022–2023）

**2022**：高校系列赛逐步恢复线下对抗，东北大学 TDT 再度夺冠。

**2023**：完整线下赛季回归，总决赛重回深圳春茧。上海交大**云汉交龙**从复活赛一路逆袭，以全胜战绩夺冠。

## 2024 赛季：地形与自主，轮腿初现

全国赛在深圳春茧收官，前四名：**上海交大交龙（冠军）、华南理工华南虎、东北大学 TDT、浙江大学 Hello World**。

- **规则**：引入**移动打击靶**，飞镖系统成为当季「主角」；工程机器人「金矿采矿」难度增加，需从方形框架里把矿掏出；规则手册迭代至 V2.1。
- **技术新动向**：
  - **飞镖超远程打击**：浙江大学完成对移动打击靶的检测与发射角度调整，实现高精度超远程打击
  - **哨兵自主决策**：哈尔滨工业大学将雷达信息融合后的决策建模为**马尔科夫决策过程**，实现路径规划、避障、追踪、回防
  - **工程全自动采矿**：深圳大学加装感知系统，实现矿槽识别 + 机械臂逆运动学解算的全自动取兑
  - **轮腿步兵开创**：上海交大交龙率先把**反关节轮腿**与四轮普通底盘结合，让步兵能上楼梯、跌倒后自行复位，成为后续「轮腿浪潮」的起点

## 2025 赛季：复杂地形，逼出「轮腿」与「边缘计算」

前四名：**上海交大交龙（冠军，三连冠）、中国科学技术大学 RoboWalker、华南理工华南虎、东北大学 TDT**。

- **规则**：赛场增设**二级台阶、狭窄隧道**等复杂地形，直接引导队伍研发轮腿平衡底盘与运动控制算法；规则迭代至 V2.1.0。
- **技术爆发**：
  - **平衡反关节轮腿普及**：在上海交大开创的基础上，各队纷纷跟进，机器人负载、机动与地形适应能力全面跃升
  - **步兵边缘计算自瞄**：搭载边缘计算模块，用神经网络识别 + 运动预测 + 弹道解算，支持远距离打击动态目标
  - **工程关节式串联机械臂**：逆运动学解算 + 自定义控制器，实现直觉化操作
  - **自主导航**：中科大基于激光雷达实现自主导航、避障、多机通信与自主追击、进攻、基地保护
  - **空中机器人轻量化**：中国石油大学（华东）RPS 整机仅 12.4kg，可负载 5kg 官方物资

## 2026 赛季：更低、更难、更强自主

总决赛 8 月 9 日在深圳春茧落幕，44 支战队、近 2000 名工程师同场竞技。前四名：**东北大学 TDT（冠军）、华南农业大学 Taurus、华东理工大学 起源、同济大学 SuperPower**。东北大学决赛 3:1 力克华南农大，再度问鼎。

- **规则**：新增**起伏地形与 250mm 低矮通道**，机器人需灵活变形、调整姿态才能通过；工程机器人任务由「取矿兑矿」升级为抓取**「能量单元」并完成「科技核心装配」**；**雷达信息波加密**，需先破译才能获取赛场信息。
- **技术新动向**：
  - **双七轴仿人机械臂**：华南农大 2 号工程机器人搭载双臂，同步抓取两组能量单元、双臂协同装配
  - **VR 头显操控**进入赛场，操控方式进一步拓展
  - 当季区域赛队伍产出专利 **150 余项**、论文近 **70 篇**

## 技术兴替：什么传了下来，什么没传下来

把十二年串起来看，规律很清晰——**能沉淀下来的，都是被规则反复验证、又被各队反复优化的「底层能力」；被淘汰的，往往是某种具体形态或「一招鲜」的打法**。

**传了下来的**：

| 技术 | 说明 |
| --- | --- |
| 摩擦轮发射机构 | 17mm / 42mm 弹丸的标准发射方式，沿用至今 |
| 麦克纳姆轮全向底盘 | 步兵标配，灵活走位的基础 |
| 滑环 | 云台 360° 无限旋转的硬件基础，几乎每台步兵都离不开 |
| 云台稳定控制 | 从「看哪儿」到「打哪儿」的核心，也是电控组必学 |
| 视觉自瞄 | 从人工打符到神经网络 + 弹道解算，一年比一年强 |
| 工程机械臂 | 取弹 → 采矿 → 能量单元装配，一路演化但从未消失 |
| 哨兵全自动 | 全自动自瞄 + 自主导航，且逐年加码 |
| 轮腿底盘 | 2024 上海交大开创，2025 起成为应对复杂地形的主流方向 |

**没传下来的**：

| 技术 / 打法 | 为什么没传下来 |
| --- | --- |
| 无人机「无敌输出」流 | 2019 夺冠打法过于强势，2021 规则直接取消原发射机构与充能机制 |
| 小陀螺自旋战术 | 规则限制自旋转速、禁止变速/偏心旋转，战术退潮（但滑环留了下来） |
| 能量机关的旧形态（九宫格 → 火焰数字） | 具体形式一换再换，但「远距离识别 + 射击」的底层能力保留了下来 |
| 纯人工瞄准 | 自瞄普及后彻底退出主流，效率无法跟上节奏 |

> 一句话总结：**形态会过时，能力不过时**。这也是为什么这套教程不教「某一年特定的机器人」，而教你「底盘、云台、控制」这些可以迁移的底层能力。

## 系列赛体系

超级对抗赛（RMUC）是核心，RoboMaster 高校系列赛还有几个侧重不同的赛项：

| 赛项 | 简称 | 形式 | 定位 |
| --- | --- | --- | --- |
| 超级对抗赛 | RMUC | 7v7 多兵种对抗 | 最核心、最综合 |
| 高校联盟赛 | RMUL | 1~3 个兵种对抗 | 门槛低，适合练兵、可晋级 RMUC |
| 高校单项赛 | RMUT | 单台机器人专项 | 单兵种技术突破 |
| 高校人工智能挑战赛 | RMUA | 无人飞行器自主竞技 | 智能感知与自主控制 |

> 超级对抗赛的具体打法和兵种分工，见 [赛制与兵种](robots-and-rules)。
