# RoboMaster 是什么

## 一句话概括

> **官方定义**：RoboMaster 机甲大师高校系列赛，作为全国大学生机器人大赛旗下赛事之一，是**专为全球科技爱好者打造的机器人竞技与学术交流平台**。

RoboMaster 是由**大疆创新（DJI）**发起的全球性机器人竞技赛事，也是**全球首个射击对抗类的机器人比赛**。参赛队伍自主研发多种机器人，在固定场地里用「弹丸」互相射击、执行任务，最终以摧毁对方基地或血量占优分出胜负。

它不只是一场比赛，更是一个「青年工程师的练兵场」：从机械结构、电子电路、嵌入式软件到机器视觉与人工智能，几乎每一个环节都由学生亲手完成。

## 官方是怎么介绍它的

以下三段为 RoboMaster 官网「关于赛事」原文，是理解这项赛事最权威、最凝练的表述：

> RoboMaster 机甲大师高校系列赛（包含超级对抗赛与高校联盟赛），作为全国大学生机器人大赛旗下赛事之一，是专为全球科技爱好者打造的机器人竞技与学术交流平台。自 2013 年创办至今，始终秉承 **“为青春赋予荣耀，让思考拥有力量，服务全球青年工程师成为追求极致、有实干精神的梦想家”** 的理念，致力于培养与吸纳具有工程思维的综合素质人才，并将科技之美、科技创新理念向公众广泛传递。

> 平台要求参赛队员**走出课堂，组成机甲战队，自主研发制作多种机器人参与团队竞技**。他们将通过大赛获得宝贵的实践技能和战略思维，在激烈的竞争中打造先进的智能机器人。高校系列赛的规模逐年扩大，每年吸引全球 400 余所高等院校参赛、累计培养近 20 万名青年工程师走向社会，并与数百所高校开展各类人才培养、实验室共建等产学研合作项目。

> 超级对抗赛作为全球首个射击对抗类的机器人比赛，在其诞生伊始就凭借其颠覆传统的机器人比赛方式、震撼人心的视听冲击力、激烈硬朗的竞技风格，吸引到全球数百所高等院校、近千家高新科技企业以及数以万计的科技爱好者的深度关注。

## 起源与发展

RoboMaster 的前身是大疆的「大学生夏令营」，一路演化成今天的全球赛事：

| 年份 | 里程碑 |
| --- | --- |
| 2013 | 大疆创办首届大学生夏令营（仅 24 人），任务是实现基于机器视觉的自主移动打靶 |
| 2014 | 夏令营扩至 100 人，开展 4v4 机器人射击对抗，竞赛规则雏形诞生 |
| 2015 | **首届机甲大师赛**（英文名 RoboMasters）正式举办，首创 5v5 射击对抗，吸引 3000 余名大学生 |
| 2016 | 研发出新一代机器人裁判系统，并首次引入海外战队 |
| 2017 | 英文名正式改为 **RoboMaster**，对抗升级为 7v7，新增工程机器人 |
| 2018 | 新增哨兵机器人；大能量机关改用动态火焰特效手写数字 |
| 2019 | 大能量机关改为「五片装甲板大风车」；同年大疆推出教育机器人 RoboMaster S1 |
| 2020 | 疫情下取消线下赛，改为「线上评审」；新增**飞镖系统、雷达站**两大兵种 |
| 2021 | 规则引入自动步兵 / 平衡步兵、工程采矿、空中机器人 17mm 机动发射机构与新经济体系 |
| 2022 | 高校系列赛逐步恢复线下对抗，赛制回稳 |
| 2023 | 完整线下赛季回归，总决赛重回深圳春茧；**上海交大云汉交龙**夺冠 |
| 2024 | 规则手册系统化迭代（V1.0.0），为复杂地形变革做铺垫 |
| 2025 | 引入**轮腿平衡底盘**与二级台阶、狭窄隧道等复杂地形；规则迭代至 V2.1.0；上海交大交龙再夺冠 |
| 2026 | 新增起伏地形与 250mm 低矮通道；工程机器人改为「能量单元 + 科技核心装配」；雷达信息波加密 |

> 总决赛通常每年八月在深圳湾体育中心（春茧体育馆）举行。截至 2026 赛季，赛事已累计吸引全球 **18 个国家和地区、941 支高校队伍**参赛，培养近 **20 万名**青年工程师。

官网也公开了赛事的组委会核心成员，可见其起点之高：

- **汪滔 / Frank Wang** —— 深圳市大疆创新科技有限公司创始人、RoboMaster 机甲大师赛发起人
- **蔡鹤皋 院士** —— 机器人及机电一体化技术专家、中国工程院院士、组委会主席
- **李泽湘 教授** —— 香港科技大学电子与计算机工程学系教授、组委会执行主席

## 为什么它「不一样」

绝大多数机器人比赛是「一个任务、一个机器人」，而 RoboMaster 是**多兵种、多学科的团队对抗**。

官网这样总结它的技术含量：

> 赛事规则充分融合了 **“机器视觉”、“嵌入式系统设计”、“机械工程”、“自主导航”、“人机交互”、“射频前端”** 等众多机器人相关技术学科，参赛队员通过项目式实践学习，在备赛及参赛的过程中提升专业技术能力，积累工程经验，为快速适应社会需求打下坚实基础。

对应到战队内的分工，就是：

- **机械**：机器人本体设计与加工，底盘、云台、发射机构、机械臂
- **电控**：电路设计、嵌入式开发、运动控制、通信与整车调试 ← 本教程的领域
- **视觉 / 算法**：自瞄、目标识别、能量机关击打、自主决策
- **项目管理**：预算、进度、供应链、对外合作

一台机器人，从设计、制作到比赛操控，**全部由学生自主完成**。这也是它被称作「最接近真实工程」的学生赛事的原因。

## 系列赛体系

RoboMaster 高校系列赛下分四大方向，各有侧重（官网原文）：

### 超级对抗赛（RMUC · 7v7 兵种对抗）

> 对战双方需自主研发不同种类和功能的机器人，在指定的比赛场地内进行战术对抗，多个机器人兵种（7v7）之间进行射击对抗。适合在以往赛季取得一定成绩的队伍及参赛经验丰富的队伍参加。

这是**最核心、最综合**的赛事，也是本教程最终要带你走向的赛场。

### 高校联盟赛（RMUL · 1~3 个兵种对抗）

> 高校联盟赛由地方学术机构及高校申办，辐射周边高校参赛，旨在促进区域性高校机器人技术交流，形成浓厚的学术氛围，为地区科技创新发展助力。参赛队伍还可通过积分体系晋级到超级对抗赛。

下设「1V1 步兵对抗赛」「3V3 对抗赛」「工程挑战赛」等赛项，门槛更低，适合新队伍练兵。

### 高校单项赛（RMUT · 单兵种技术突破）

> 高校单项赛自 2016 赛季开始举办，前身为技术挑战赛。侧重机器人某一技术领域的学术研究，旨在鼓励各参赛队深入挖掘技术，精益求精，将机器人做到极致。

设「步兵竞速与智能射击」「工程采矿」「飞镖打靶」「英雄吊射」等专项。

### 高校人工智能挑战赛（RMUA · 无人飞行器赛事）

> 高校人工智能挑战赛旨在加速推动智能感知、定位导航与自主控制等领域的技术创新，并积极促进相关创新成果在无人飞行器领域开展转化与应用，发掘一批优质潜力项目和创新人才，为无人智能产业培养更多的未来技术领军人才。

| 赛项 | 简称 | 形式 | 参赛对象 |
| --- | --- | --- | --- |
| 超级对抗赛 | RMUC | 7v7 多兵种射击对抗 | 有一定成绩 / 经验丰富的队伍 |
| 高校联盟赛 | RMUL | 1~3 个兵种射击对抗 | 起步阶段 / 新组建的队伍 |
| 高校单项赛 | RMUT | 单台机器人专项 | 全民爱好者 / 技术突破 |
| 高校人工智能挑战赛 | RMUA | 无人飞行器自主竞技 | 高校团队 |

## 赛事文化

这是官网最动人的一部分，也是很多人被 RoboMaster「圈粉」的原因——它把比赛升华为一种文化：

> **赛事愿景**：为青春赋予荣耀，让思考拥有力量；以学术价值为根基，培养具有工程思维、拥有实干精神的综合素质人才，并将科技之美、科技创新理念向公众传递。
>
> **赛事使命**：为青春赋予荣耀，让思考拥有力量，服务全球青年工程师成为拥有实干精神的梦想家。
>
> **赛事宗旨**：以先进科学教育理念，培养未来优秀工程师人才；以严谨科技竞赛规则，提升机器人竞赛整体水平，推动机器人行业技术发展；以前沿科技创新手段，激发学子对科技创新的兴趣与热爱。
>
> **赛事理念**：以人才为核心，打造全球顶级大学生机器人科技创新竞技赛事；传播崇尚科学与创新、擅于反思、勇于实践、热爱分享、以穷究原理、洞悉本质为研发导向的青年工程师文化。

**赛事价值观**：初心高于胜负；每一战，都是成长；大道至简，实干为要；极致者可敬，创新者无畏；拼搏源自热爱，合作成就奇迹；尊重对手、尊重细节、尊重努力。

## 大赛外延

RoboMaster 不止是比赛，大疆以传播青年工程师文化为核心，衍生出一批原创文化 IP：

> 相继推出了「《机甲大师》同名动画」「《RoboMaster 机甲大师》赛事纪录片」「《超能理工派》真人秀」等原创文化 IP 项目，希望通过高质量的文化作品，引导社会公众对机器人科学领域的认知兴趣和参与热情。

- 动画《机甲大师》——中日合制原创电视动画
- 真人秀《超能理工派》——国内首档原创科技竞技真人秀
- 赛事纪录片《机甲大师》——首部纪录青年工程师成长的纪录片

## 赛事收获

除了技术，RoboMaster 对个人的「硬回报」也很实在：

- **人才培养**：大疆为参赛队伍提供物资购买优惠，截至 2026 赛季帮助战队节省参赛成本达 **5394 万元+**；赛事培训体系涵盖参赛攻略、课程沙龙、开源材料等。
- **专属招聘通道**：截至目前已有 **超过 1000 位**参与过 RoboMaster 的优秀人才入职大疆，成为推动科技发展的中坚力量。大疆为 RoboMaster 参赛队员开放专属招聘通道，享特殊权益。
- **奖项激励**：设赛事奖项、开源奖、杰出贡献奖、组织奖、技术突破奖、学术激励奖等，鼓励开源与技术深耕。

## 为什么值得你投入

对刚加入电控组的你来说，RoboMaster 的意义在于：

1. **真实**：要解决的都是「让机器人在对抗里可靠地动起来」的真问题，不是玩具
2. **系统**：逼着你去打通「硬件 → 软件 → 控制 → 调试」的完整链路
3. **成长**：和一群目标一致的人，把一个复杂系统从零做出来并送上赛场
