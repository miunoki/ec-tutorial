# 第一章 · 认识 RoboMaster

::: tip 本章定位
本章**不讲技术细节**，只做一件事：让你真正看懂 RoboMaster 这场比赛 —— 它是什么、怎么打、有哪些兵种、经历了哪些技术革新与规则变化，以及我们电控组在这盘大棋里的位置。
:::

## 学习目标

学完本章，你应该能：

- 说清楚 RoboMaster 是什么、由谁发起、在机器人圈子里有什么地位
- 看懂超级对抗赛的赛制与胜负判定，认得每一种机器人
- 了解能量机关、视觉自瞄等几大技术革新的来龙去脉
- 知道近几年（尤其 2025 / 2026 赛季）规则更新的大方向
- 明白电控组负责什么、为什么要学后面的电控知识
