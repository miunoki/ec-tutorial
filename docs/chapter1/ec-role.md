# 电控组是做什么的

看完比赛、兵种和技术革新，你可能已经隐约感觉到：一台机器人要真正「上得了赛场」，光有机械骨架是不够的。**让骨架活起来、动起来、听指挥的，就是电控。**

## 电控组负责什么

在一支 RoboMaster 战队里，电控组通常负责这条链路：

| 环节 | 具体内容 |
| --- | --- |
| 电子电路 | 主控板、电源、驱动、传感器接口的设计与选型 |
| 嵌入式开发 | 在 STM32 等单片机上写固件，驱动外设、收发数据 |
| 运动控制 | 电机控制、PID 闭环、底盘运动学解算 |
| 通信 | CAN / UART / SPI / I2C 等总线，把各个模块串起来 |
| 调试 | 调参、抓日志、定位问题，把系统调到可靠 |

简单说：**机械组造出「身体」，电控组装上「神经和大脑」。**

## 我们这套教程的最终目标

明确一下你要到达的终点 —— 学完这套教程，你要能：

> **独立调试一台「任意底盘 + 双轴云台」的小车**（不含摩擦轮、功率控制等部分）。

拆解一下这句话：

- **任意底盘**：不管队里用的是麦轮、全向轮还是别的底盘，你都能把它驱动起来、让它按指令运动
- **双轴云台**：俯仰轴（pitch）+ 偏航轴（yaw）两个自由度的云台，能稳定、能指向目标
- **独立调试**：从接线、写代码到调参、定位问题，你能自己走通全流程

这已经是电控开发的核心能力了。至于更进阶的摩擦轮发射、功率控制、裁判系统对接等，属于后续再深入的内容。

## 你需要具备的基础

- 一点点 C 语言基础（没有也没关系，第二章会带）
- 一颗愿意「对着硬件死磕」的心 —— 电控的乐趣和难点，都在于软硬结合
