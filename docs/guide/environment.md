把电控开发的整套工具链装好，是动工前的第一步。这里的目标是：**从零到能编译、烧录、调试一个最小 STM32 工程**。

## 你将学到

- 安装 STM32CubeMX 并生成一个最小工程
- 安装并配置 Keil MDK（或 CLion）编译器与下载器驱动
- 用 ST-Link / J-Link 完成烧录与在线调试
- 用串口助手与单片机收发数据（后续调试的命脉）

## 建议大纲

1. **主控选型** —— 战队用什么板子（如 STM32F4 / H7），配套下载器
2. **CubeMX 安装与工程生成** —— 选芯片、配时钟、生成 Keil 工程
3. **Keil MDK 安装与编译** —— Pack 安装、编译第一个工程
4. **ST-Link / J-Link 烧录调试** —— 驱动、接线、单步调试
5. **串口助手与驱动** —— CH340 / USB 转串口、收发测试
6. **可选：CLion / VSCode + 插件** —— 更现代的编辑体验
