电控工程是多人协作的，代码版本管理是**团队开发的生命线**。学会 Git，才能安全地和队友一起改代码。

## 你将学到

- 版本控制解决什么问题，为什么战队必须用 Git
- `clone / add / commit / push / pull` 的日常工作流
- 分支与合并，解决冲突的基本方法
- 战队自己的提交规范与协作约定

## 建议大纲

1. **为什么需要版本控制** —— 没有 Git 的灾难现场
2. **Git 基本命令** —— 仓库、暂存、提交、推送、拉取
3. **分支与合并** —— feature 分支、Pull Request、Code Review
4. **解决冲突** —— 冲突是怎么产生的、如何合并
5. **战队规范** —— 提交信息格式、分支命名、代码风格（clang-format）
6. **常见翻车与补救** —— `revert`、`reset`、找回误删
