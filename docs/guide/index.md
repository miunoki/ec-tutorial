# 开始入门

::: tip 本阶段目标
这是整份教程的「先导」—— 在你真正读懂战队高级知识库（如 zju-helloworld Wiki）之前，先帮你把**工具链、语言基础、协作习惯**这三块地基打牢。
:::

欢迎来到电控组！这份教程假设你**没有任何嵌入式基础**，只要会基本的使用电脑，就能跟着走完。

## 本阶段包含

- **学习路线图** —— 四阶段全景，明确每一步该学什么、学到什么程度
- **开发环境搭建** —— CubeMX、Keil / CLion、ST-Link 烧录调试一条龙
- **C / C++ 基础** —— 电控开发用得到的那部分语言知识
- **Git 与团队协作** —— 和队友一起写代码的正确姿势

## 怎么学

1. 按左侧目录从上往下读，**先动手跑通环境**再往下走
2. 每篇的「建议大纲」是内容骨架，正文由老队员陆续补全
3. 遇到问题先在队内群提问，再把答案补回教程（见[贡献指南](/about/contribute)）

## 下一步

环境就绪后，进入 [嵌入式基础](/embedded/)。
