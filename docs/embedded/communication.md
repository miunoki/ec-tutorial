机器人的设备靠总线连在一起：**CAN** 连电机和裁判系统，**SPI** 连 IMU，**I2C** 连一些传感器。吃透它们的区别，才能选对接口。

## 你将学到

- 三种协议的工作方式、速度、拓扑与适用场景
- CAN 总线的帧格式、仲裁与 1Mbps 实战配置
- SPI / I2C 读写传感器（如 IMU、EEPROM）的基本套路

## 建议大纲

1. **协议对比总览** —— CAN / SPI / I2C / UART 各自定位
2. **CAN 深入** —— 差分信号、仲裁、滤波器、错误处理（电控重点）
3. **SPI** —— 主从、时钟极性相位、DMA 读取 IMU
4. **I2C** —— 起始停止、地址、读写时序
5. **实战** —— CAN 驱动电机、SPI 读 BMI088
