# 嵌入式基础

::: tip 本阶段目标
学会和硬件「对话」：用 STM32 的外设读写传感器、驱动执行器、和队友的设备通信。这是电控最核心的地基。
:::

机器人电控的本质，是让主控芯片（通常是一颗 STM32）**感知**（读取传感器）→ **决策**（运行算法）→ **执行**（驱动电机等）。本阶段解决「感知与执行」的底层能力。

## 本阶段包含

- **STM32 入门** —— 芯片是什么、CubeMX 工程结构、HAL 库
- **外设逐个击破** —— GPIO、中断、定时器、PWM、UART、ADC
- **通信协议** —— CAN / SPI / I2C 的对比与使用场景
- **RTOS 入门** —— 用操作系统更好地组织多任务

## 建议顺序

1. 先 [STM32 入门](/embedded/stm32-intro)，理解工程从哪来
2. 再按 **GPIO → 中断 → 定时器/PWM → UART → ADC** 逐个做实验
3. 掌握 [通信协议](/embedded/communication)，重点吃透 CAN
4. 最后 [RTOS 入门](/embedded/rtos)，为复杂工程打底
