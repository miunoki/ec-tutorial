底盘、云台、发射都靠遥控器下达指令。学会用 DBUS 接收机读取遥控器数据，才能让机器人「听你的话」。

## 你将学到

- DR16 / DT7 遥控器与接收机的接线方式
- DBUS 帧格式与解析方法
- 把摇杆 / 拨杆数据映射到底盘速度与云台指令

## 建议大纲

1. **遥控器与接收机** —— DR16 / DT7 选型、接收机接线（UART）
2. **DBUS 协议** —— 帧格式、通道字段、校验
3. **通道解析** —— 摇杆 / 拨杆 / 拨轮 / 鼠标键盘
4. **数据映射** —— 死区处理、量程缩放、到底盘 / 云台指令
5. **实战** —— 读取遥控器并打印通道值
