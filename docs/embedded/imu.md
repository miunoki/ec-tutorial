IMU（惯性测量单元）是云台自稳、底盘跟随的「平衡感」。这里不只讲怎么读数据，更讲怎么把数据变成机器人的姿态。

## 你将学到

- 陀螺仪与加速度计的工作原理与区别
- BMI088 / MPU6050 等常见 IMU 的 SPI / I2C 读取
- 互补滤波 / Mahony 姿态解算，得到欧拉角或四元数

## 建议大纲

1. **IMU 原理** —— 陀螺仪、加速度计、磁力计
2. **常见芯片** —— BMI088 / MPU6050 的参数与接口
3. **驱动与读取** —— SPI / I2C 读取原始数据
4. **姿态解算** —— 互补滤波、Mahony 算法
5. **四元数与欧拉角** —— 姿态表示与换算
6. **零偏与校准** —— 漂移抑制、静止校准
7. **实战** —— 读出姿态并在上位机可视化
