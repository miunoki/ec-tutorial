嵌入式世界的「Hello World」—— 用 GPIO 点亮一颗 LED，并读懂输入/输出模式。

## 你将学到

- GPIO 是什么，输入与输出模式的区别
- 推挽、开漏、上下拉等配置的含义
- 用 HAL 库读写引脚，实现点灯与按键检测

## 建议大纲

1. **GPIO 原理** —— 引脚、模式寄存器、电气特性
2. **输出模式** —— 推挽 / 开漏、驱动 LED
3. **输入模式** —— 上拉 / 下拉 / 浮空、读取按键
4. **HAL 库操作** —— `HAL_GPIO_WritePin` / `ReadPin` / `TogglePin`
5. **实验** —— 点灯、按键控制 LED、流水灯
