# 第二章 · 电控基础

::: tip 本章目标
学完这一章，你将拥有一套**完整的开发流程**：会用 C/C++ 写代码、搭好嵌入式开发环境、用 Git 管理代码。这是第三章「让机器人动起来」和第四章「云台与整车联调」的入场券。
:::

本章分三部分：

| 部分 | 主题 | 你会得到 |
| --- | --- | --- |
| 第一部分 | [C / C++ 基础](cpp-basics) | 面向嵌入式的 C/C++ 功底，为封装电机/传感器打底 |
| 第二部分 | [纳新环境配置](env-setup) | CubeMX + VS Code + CMake + Ozone 一整套可用的开发环境 |
| 第三部分 | [Git 使用指南](git-guide) | 在 VS Code 里提交、回滚、分支协作，以及队内提交规范 |

## 你将学到

- **C / C++**：变量、指针、结构体、位运算、`volatile`/`static`、类与继承、虚函数
- **开发环境**：STM32CubeMX → CMake + Ninja + arm-none-eabi-gcc 构建 → SEGGER Ozone 调试
- **Git**：提交与上传、历史查看、撤销与回滚、分支合并与冲突解决、提交规范

> 说明：STM32 的**外设**（GPIO / 定时器 / PWM / UART / ADC）和 **CAN 通信**放到第三章讲电机时边用边学，**SPI / I2C 读 IMU** 留到第四章。本章只把「写代码、搭环境、管代码」这三件事的地基打牢。
