# 关于本教程

::: tip 待补充
战队简介、历史战绩、组织架构与联系方式仍需电控组补充。
:::

这份教程是**电控组面向新成员的入门知识库**，目标是让零基础的新人按一条清晰的路径，最终能**独立调试一台「任意底盘 + 双轴云台」的小车**（不含摩擦轮、功率控制等部分）。

## 定位

它定位为战队高级知识库（如 [zju-helloworld Wiki](https://zju-helloworld.github.io/Wiki/)）的**先导**——先把比赛认知、工具链、语言、外设、运动控制、云台联调这些地基打牢，之后再去研读更深的组件级文档。

## 面向谁

- 新加入电控组的同学（零基础可读）
- 想系统复习基础的老队员
- 想了解电控工作内容的其它组同学

## 四大章节

| 章节 | 内容 | 关卡 |
| --- | --- | --- |
| 第一章 · 认识 RoboMaster | 赛制、兵种、技术革新、规则更新 | 直接进入第二章 |
| 第二章 · 电控基础 | C/C++、STM32、外设、通信协议 | 问卷解锁第三章 |
| 第三章 · 运动控制 | 电机、PID、底盘运动学 | 问卷解锁第四章 |
| 第四章 · 双轴云台与整车联调 | IMU、双轴云台、系统整合与调试 | 结业问卷 |

> 自第二章起，每一章结束需完成问卷、通过后才能进入下一章。通过进度保存在本机浏览器。
