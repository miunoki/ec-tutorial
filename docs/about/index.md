这份教程是**电控组面向新成员的入门知识库**，目标是让零基础的新人按一条清晰的路径，成长为能独立参与战队电控开发的成员。

## 定位

它定位为战队高级知识库（如 [zju-helloworld Wiki](https://zju-helloworld.github.io/Wiki/)）的**先导**——先把工具链、语言、外设、运动控制这些地基打牢，之后再去研读更深的组件级文档。

## 面向谁

- 新加入电控组的同学（零基础可读）
- 想系统复习基础的老队员
- 想了解电控工作内容的其它组同学

## 内容结构

| 分区 | 内容 |
| --- | --- |
| 入门指南 | 学习路线、环境搭建、C/C++、Git |
| 嵌入式基础 | STM32 外设、通信协议、RTOS |
| 运动控制 | 电机、CAN、PID、底盘、云台 |
| 进阶实战 | 裁判系统、发射、功率、状态机、调试 |
