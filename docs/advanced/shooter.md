发射机构（摩擦轮 + 拨弹）是机器人的「输出」。这里不只要让它射得准，还要处理卡弹、堵转等异常。

## 你将学到

- 摩擦轮发射的原理与转速闭环
- 拨弹机构与供弹节奏控制
- 卡弹 / 堵转的检测与处理

## 建议大纲

1. **发射原理** —— 摩擦轮、单发 / 连发
2. **摩擦轮转速控制** —— PID 闭环稳定初速
3. **拨弹机构** —— 拨弹电机、供弹时序
4. **异常处理** —— 卡弹检测、反转排障
5. **状态机整合** —— 单发 / 连发 / 停止切换
