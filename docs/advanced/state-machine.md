当机器人行为变复杂（待机、瞄准、发射、自检……），靠一堆 `if` 会越来越乱。状态机帮你把行为组织得清晰可控。

## 你将学到

- 有限状态机的概念与建模方法
- 用状态机组织机器人行为（如发射流程）
- 多任务调度与 RTOS 的配合

## 建议大纲

1. **为什么需要状态机** —— 复杂逻辑的可维护性
2. **状态机基础** —— 状态、事件、转移
3. **机器人行为建模** —— 待机 / 自检 / 瞄准 / 发射
4. **任务调度** —— 控制周期、优先级、与 [RTOS 入门](/embedded/rtos) 的配合（本页聚焦行为建模，RTOS 原语见嵌入式基础）
5. **实战** —— 重构发射机构为状态机
