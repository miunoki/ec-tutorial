# 进阶实战

::: tip 本阶段目标
把前面的能力拼成一台真正的参赛机器人：对接裁判系统、控制发射、管理功率，并用工程化的方法组织代码和调试。
:::

到这里你已经能驱动电机、做闭环、解算运动学。进阶阶段讲的是**赛场上的真实问题**，以及让代码从「能跑」到「可靠、可维护」的工程化方法。

## 本阶段包含

- **裁判系统** —— 与比赛裁判系统通信，读取血量 / 功率等数据
- **发射机构** —— 摩擦轮、拨弹、卡弹处理
- **功率控制** —— 缓冲能量管理与功率限制
- **状态机与任务调度** —— 组织复杂机器人行为
- **调试与调参** —— 定位问题、优化性能的方法论

## 建议顺序

本阶段各篇相对独立，可根据战队当前任务按需学习。建议先读 [状态机与任务调度](/advanced/state-machine) 建立工程化思维，再进入具体模块。
