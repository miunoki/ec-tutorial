电机是机器人的「肌肉」。先搞清楚电机怎么转、怎么调速、怎么测速，才能谈后面的闭环控制。

## 你将学到

- 有刷 / 无刷电机（BLDC）的区别与工作原理
- 电调（ESC）如何用 PWM 控制电机转速
- 编码器如何测量转速与角度

## 建议大纲

1. **电机类型** —— 直流有刷、无刷 BLDC、舵机
2. **电调与调速** —— PWM 占空比 → 转速、正反转
3. **编码器** —— 光电 / 磁编码器、测速与计角
4. **速度反馈** —— 从编码器脉冲换算实际转速
5. **实验** —— PWM 调速、读取编码器转速
