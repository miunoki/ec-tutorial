RoboMaster 的电机（M3508 底盘、GM6020 云台、M2006 等）通过 **CAN 总线**通信。学会用 CAN 发指令、读反馈，你就正式「上车」了。

## 你将学到

- 大疆 RM 系列电机的型号与参数（3508 / 6020 / 2006）
- CAN 发送控制指令、解析电机反馈数据
- 读取转速、角度、温度等信息，为闭环做准备

## 建议大纲

1. **RM 电机概览** —— 3508 / 6020 / 2006 的用途与参数
2. **CAN 协议回顾** —— ID 分配、数据帧格式
3. **控制指令** —— 电流指令、ID 与数据段组织
4. **反馈解析** —— 转速、机械角度、温度等字段
5. **实验** —— CAN 驱动电机转动、读取并打印反馈
