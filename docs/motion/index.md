# 运动控制

::: tip 本阶段目标
让机器人「动起来」：驱动电机、做闭环控制、解算底盘运动学、稳定云台。这是电控最有成就感、也最能出成果的阶段。
:::

有了嵌入式基础，你现在能把数据读进来、写出去。接下来要把它们变成**精确的运动**——从一颗电机的转速，到整台车在全场的位移。

## 本阶段包含

- **电机基础** —— 电机类型、电调、PWM 调速、编码器测速
- **CAN 电机** —— 大疆 RM 系列电机（3508 / 6020）的驱动与反馈
- **PID 控制** —— 位置环、速度环、串级 PID 与调参
- **底盘运动学** —— 麦轮 / 全向轮的逆解算，让车全向移动
- **云台控制** —— 云台电机的角度控制与自稳

## 建议顺序

1. 先 [电机基础](/motion/motor-basics) 搞懂电机怎么转、怎么测速
2. 再 [CAN 电机](/motion/can-motor) 驱动大疆电机、读反馈
3. 重点吃透 [PID](/motion/pid) —— 这是整个运动控制的核心
4. 最后分别做 [底盘](/motion/chassis) 和 [云台](/motion/gimbal)
