麦克纳姆轮（麦轮）和全向轮让底盘能**全向移动**。你要做的，是把遥控器给的「前进 / 平移 / 旋转」指令，解算成每个轮子的转速。

## 你将学到

- 麦轮 / 全向轮 / 舵轮底盘的运动学原理
- 运动学逆解算：把底盘速度分解到各轮
- 结合 PID 实现闭环驱动的完整流程

## 建议大纲

1. **底盘类型** —— 麦轮、全向轮、舵轮的对比
2. **麦轮运动学** —— 正解与逆解算公式推导
3. **遥控器指令解算** —— 平移 / 旋转 / 合成速度
4. **闭环驱动** —— 各轮速度环闭环
5. **进阶** —— 小陀螺、跟随模式、功率限制
